# Projeto_Gerenciamento_Configuracao
Projeto prático de gerenciamento de configuração e controle de versão utilizando Git e GitHub.

## Atualização do Projeto

O projeto utiliza Git e GitHub para o gerenciamento de configuração
e controle de versão dos artefatos de software.

## Funcionalidades

- Controle de tarefas da equipe.
- Registro de atividades.
- Organização dos artefatos.
- Compartilhamento de arquivos entre colaboradores.

Atualização realizada durante a aula prática de Projeto de Software.
